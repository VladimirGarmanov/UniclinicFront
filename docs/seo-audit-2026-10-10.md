## Проверки

```bash
npm run build
npm run check
npm run check:audit
npm run preview
# При запущенном локальном API:
npm run check:http
```

Backend: `cd ../UniclinicBack && .venv/bin/python scripts/smoke.py`.

`check:audit` проверяет именно готовый HTML: одинаковые ссылки шапки, скрытые CMS-поля, формы, соответствие FAQPage ответам, размеры каждого социального превью, alt, sitemap и бюджет hero. Результат записывается в `.generated/seo-audit-check.json`. Backend smoke работает на одноразовой БД и синтетических данных, без SMTP.

Браузерный просмотр в этой сессии не завершён: встроенный браузер недоступен, нативный захват Safari вернул ошибку. Поэтому визуальное поведение после hydration, мобильный layout и отправка формы через GUI не объявляются проверенными. Серверный HTML, HTTP и обработчик API проверяются отдельно.

## Редакторская работа и измерение

Первая очередь материалов: подготовка к консультации; подготовка к колоноскопии; какие симптомы обсуждать с колопроктологом; восстановление после согласованных вмешательств. План — 2–4 материала в месяц с именем действительного автора, источниками и реально состоявшимся медицинским рецензированием. Старые анонсы сохраняют исторические даты. Сначала публикация готового материала, затем новая дата; смена © в подвале не обновляет статью.

После публикации измерять: индексацию канонических URL; небрендовые показы/CTR по кластерам; органические посещения услуг; подтверждённые заявки и звонки; мобильные LCP/INP/CLS. До и после сравнивать одинаковые периоды с учётом сезонности. Полезные события уже заведены в `src/utils/analytics.js`; подключение внешнего счётчика и коллтрекинга требует его настоящих реквизитов и отдельной настройки, а не фиктивного ID.
